### Домашнее задание к занятию «Репликация и масштабирование. Часть 1»

### Задание 1
На лекции рассматривались режимы репликации master-slave, master-master, опишите их различия.

Master-Slave
---

+ Один сервер назначается как master — он принимает все операции записи и чтения.

+ Один или несколько серверов работают как slaves — они только читают данные и получают копии изменений от master-сервера.

+ Репликация происходит в одну сторону: от master к slave.

+ Простой в настройке и поддержке.

+ Хорошо масштабируется на чтение — можно распределить нагрузку по slave-серверам.

+ Все записи идут только на master, возможен bottleneck.

+ При сбое master необходимо вручную или через сторонние инструменты переключить одного из slave в режим master.

+ Задержка репликации: slave может немного отставать от master.

Master-Master
---
+ Высокая доступность: при падении одного master'а другой продолжает работу без задержек.

+ Балансировка как чтения, так и записи.

+ Сложность настройки и управления.

+ Возможны конфликты записи (если один и тот же объект изменён на обоих серверах) — нужны механизмы разрешения конфликтов.

+ Репликация может быть медленнее из-за сложности синхронизации.

Ответить в свободной форме.
